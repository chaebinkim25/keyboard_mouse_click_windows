# keyboard_mouse_click_windows

간단 설명
- Windows에서 로우레벨 키보드 훅을 사용해 특정 키(기본: vkCode 192, 보통 `~` 또는 `\``)를 누르면 마우스 왼쪽 클릭을 시뮬레이션하는 간단한 C++ 예제입니다.

파일
- keyboard_mouse_click.cpp — 로우레벨 키보드 훅 설치, 키 이벤트 감지, SendInput을 이용한 마우스 클릭 발생

동작 요약
- 프로그램 실행 시 전역(시스템) 키보드 훅을 설치합니다.
- 지정한 가상키(vkCode 192)를 누르면 50ms 지연 후 마우스 왼쪽 버튼 다운/업을 SendInput으로 전송합니다.
- 콘솔에 키다운/업 로그를 출력합니다.
- 종료: 프로세스를 종료하면 훅이 해제됩니다.

빌드 (예)
- Visual Studio (MSVC)
  cl /EHsc keyboard_mouse_click.cpp user32.lib
- MinGW/G++
  g++ keyboard_mouse_click.cpp -o keyboard_mouse_click.exe -luser32

간단 사용법
- 빌드 후 실행하면 콘솔이 떠 있고 훅이 동작합니다.
- 기본적으로 vkCode 192(키보드의 `~` 키)를 누르면 마우스 왼쪽 클릭이 한 번 발생합니다.
- 종료하려면 콘솔 창을 닫거나 프로세스를 종료하세요.

주의사항
- SendInput/SetWindowsHookEx 등은 대상 프로그램의 권한에 따라 동작이 제한될 수 있습니다(관리자 권한 필요할 수 있음).
- 훅 콜백 내에서 블로킹 작업(printf 등)은 성능/응답성에 영향을 줄 수 있습니다. 디버깅 후 제거 권장.
- 현재 코드는 특정 키에 대해 단발 클릭만 발생합니다. 키를 누르고 있는 동안 반복 클릭을 원하면 타이머 유지/해제 로직을 추가해야 합니다.
- 훅을 설치했을 때 반환값(hHook) 체크 및 오류 처리가 없습니다. 안정성 향상을 위해 추가 권장.

간단 개선 제안
- hHook == NULL 검사 및 오류 로그 추가
- SendInput 반환값 확인 및 실패 시 GetLastError 로깅
- 디버그 로그를 조건부(#ifdef DEBUG)로 감추기
- 키 누름 상태 유지 중 반복 클릭이나 키업 시 타이머 해제 기능 추가

문의 / 기여
- 간단한 수정(반복 클릭, 키 변경 등)을 원하시면 변경하고 싶은 동작을 알려주세요. 바로 코드 예제를 드리겠습니다.
